# 🚚 Transalias – National & International Transport Management System

This project is a **web-based transport management system** developed as part of a Bachelor’s final year project in Computer Systems Engineering.  
It provides logistics companies with an efficient and centralized solution for managing transport operations, clients, invoices, and carriers.  

---

## 🎯 Project Objectives
The main goal of this system is to **optimize and digitalize the management of transport operations** at both national and international levels.  

Key objectives include:  
- Managing **clients** and **carriers**  
- Tracking **transport cases (files)** from creation to closure  
- Managing **invoices** with payment status (paid / unpaid)  
- Handling **debit notes**  
- Providing **statistics and reports** through an interactive dashboard  
- Ensuring **security and user management**  

---

## 🖼️ Main Features
- Interactive **dashboard** with real-time statistics  
- **Transport cases management** (new and closed)  
- **Invoice management** (paid / unpaid tracking)  
- **Debit notes management**  
- User authentication and **security module** (Admin panel)  
- Modern, **responsive UI** for better user experience  

---

## ⚙️ Technologies Used
- **Backend**: Laravel  
- **Frontend**: Blade / Chart.js  
- **Database**: MySQL  
- **Version control**: Git & GitHub
